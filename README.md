# RCD - Repositório Central de Dados

Repositório público de dados para aulas, projetos e exercícios de:

- Power BI
- Excel
- Power Query
- Python
- Banco de Dados
- Ciência de Dados
- Inteligência Artificial

## Estrutura

- Dados_Brutos
- Dados_Tratados
- Dicionario_de_Dados
- Dashboards_Exemplo
- Desafios

## Objetivo

Centralizar conjuntos de dados para uso educacional em diferentes turmas e cursos.
